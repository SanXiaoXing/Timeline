## 问题陈述

现有的 Timeline 项目是一个个人人生记录网站，用于展示人生节点大事、工作成果和心态变化历程。当前实现虽然动画精美，但存在以下问题：

1. **视觉形式太传统**：成就卡片虽然精美，但感觉太像"卡片"了，不够有趣
2. **缺乏互动探索感**：展示方式比较静态，缺乏探索和发现的乐趣
3. **动画效果单一**：虽然精美，但看多了会觉得单调
4. **内容模块割裂**：成就系统、项目展示、心态记录等模块比较割裂，没有统一的叙事

用户希望以**极简文艺风格**（类似《Kinfolk》杂志）重新设计，提供**沉浸式阅读体验**，像翻阅精美杂志一样浏览人生节点。

## 什么让它有趣

**核心体验**：像翻阅一本精美的文艺杂志，每一页都是一段人生故事。极简的排版、大量的留白、优雅的过渡动画，让读者沉浸在内容本身，而不是被炫技的视觉效果分散注意力。

**独特之处**：
- 不是游戏化的成就系统，而是有深度的人生叙事
- 不是炫技的粒子效果，而是克制的优雅
- 不是割裂的模块，而是流动的故事线
- 不是为了展示技术，而是为了讲述人生

## 约束条件

1. **技术栈**：保留 Astro + GSAP + Tailwindcss（用户熟悉且强大）
2. **内容数据**：保留现有的内容数据结构（achievements、projects、xing）
3. **性能**：必须保持快速加载（作品集需要给面试官好印象）
4. **响应式**：必须在移动端和桌面端都有良好体验
5. **可维护性**：代码结构要清晰，方便后续迭代

## 前提

1. **极简风格需要克制**：不是所有地方都需要动画，留白和静止本身就是设计
2. **内容优先于形式**：视觉设计应该服务于内容叙事，而不是喧宾夺主
3. **渐进式交互**：基础的阅读体验不需要 JavaScript，交互是渐进增强
4. **杂志排版需要网格系统**：需要建立一套清晰的网格和排版系统

## 考虑的方案

### 方案 A：纯 Astro 静态站点 + CSS 动画
- **优点**：性能极佳，维护简单，符合极简风格
- **缺点**：交互有限，动画不如 GSAP 灵活
- **工作量**：中等（约 1-2 周）

### 方案 B：Astro + React + GSAP（已选）
- **优点**：保留现有技术栈，GSAP 强大灵活，React 组件可按需加载
- **缺点**：需要重新设计所有组件，工作量较大
- **工作量**：大（约 3-4 周）

### 方案 C：Next.js + Tailwind Typography + MDX
- **优点**：内容创作便捷，图片优化，生态丰富
- **缺点**：迁移成本高，可能过度重量级
- **工作量**：大（约 3-4 周）

## 推荐方案

**方案 B：Astro + React + GSAP**

**理由**：
1. 用户已经熟悉 GSAP，学习成本为零
2. GSAP 比 CSS 动画更强大，可以实现杂志翻页、滚动触发等复杂效果
3. React 组件可以按需加载，不会影响首屏性能
4. 可以保留现有的内容数据结构，只需重新设计视觉层
5. Astro 的静态生成保证了快速加载

**核心设计理念**：
- **网格系统**：建立 12 列网格，定义清晰的间距系统（8px 基准）
- **排版系统**：选择一套优雅的字体组合（衬线标题 + 无衬线正文）
- **色彩系统**：极简的黑白灰 + 一个点缀色（可能是米色或淡蓝）
- **动画系统**：克制的动画，只在关键过渡处使用（页面切换、滚动触发）
- **图片系统**：大量使用高质量图片，图片是杂志的灵魂

## 开放问题

1. **字体选择**：衬线字体选择什么？（Playfair Display、Cormorant、Libre Baskerville？）
2. **点缀色**：极简风格需要一个点缀色，选择什么色调？
3. **图片来源**：人生节点的配图从哪里来？需要拍摄还是使用素材？
4. **内容重组**：如何将现有的成就、项目、心态记录重新组织成连贯的叙事？
5. **首页设计**：首页应该展示什么？是一个时间线、还是一个精选集、还是一篇欢迎文章？

## 成功标准

1. **视觉一致性**：所有页面都遵循统一的网格和排版系统
2. **性能**：Lighthouse 性能分数 > 90
3. **可读性**：正文行高 1.6-1.8，段落间距合理，阅读体验舒适
4. **响应式**：移动端和桌面端都有良好体验
5. **叙事性**：内容不再是割裂的模块，而是流动的故事
6. **克制**：动画使用克制，不是炫技，而是服务于叙事

### Error & Rescue Registry
静态站点，无后端服务。运行时风险：
- GSAP 动画失败 → 降级模式（静态内容仍可见）
- 图片加载失败 → 标准 `<img>` fallback（浏览器原生）
- 内容构建失败 → Astro 构建时报错，不部署
- 字体加载失败 → font-display: swap 回退到系统字体
