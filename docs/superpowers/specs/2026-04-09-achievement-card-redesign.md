# 成就卡片重构设计规范

**日期**：2026-04-09
**主题**：成就卡片重构 — 游戏解锁弹窗风
**状态**：已批准

---

## 1. 概述与目标

当前成就卡片存在以下问题：
- 翻转交互冗余，正反两面信息重复（icon + 名称同时出现在两面）
- 稀有度视觉差异不够明显，未能体现"传说"比"普通"的珍贵感
- 已解锁 vs 未解锁的对比不够强烈，缺乏游戏化的仪式感

本次重构目标：
- 采用**游戏解锁弹窗风**（Steam/PS 成就风格）
- 取消翻转，改为**点击弹出详情弹窗**
- 所有卡片同尺寸，通过**特效层级**区分稀有度
- 已解锁华丽，未解锁暗淡，形成强烈对比

## 2. 卡片设计（单面展示）

### 2.1 已解锁卡片

```
┌─────────────────────────┐
│                         │
│       ✨ [icon] ✨      │  ← 发光 icon，稀有度越高光效越强
│                         │
│     成就名称            │  ← 粗体，深色文字
│                         │
│    [稀有度徽章]         │  ← 稀有度标签
│                         │
└─────────────────────────┘
```

- 背景：`bg-gradient-to-br` + 稀有度对应渐变色
- icon 容器：`w-16 h-16 rounded-xl`，带稀有度边框颜色和发光 `box-shadow`
- 名称：`font-bold text-base`，`text-neutral-800`
- 稀有度徽章：`px-2 py-0.5 rounded text-[10px] font-bold uppercase tracking-wider`，背景为稀有度淡色，文字为稀有度主题色

### 2.2 未解锁卡片

```
┌─────────────────────────┐
│  🔒                     │  ← 左上角小锁图标
│                         │
│      [icon 灰度]        │  ← 灰度/剪影 icon
│       ╭───╮             │
│       │░░░│             │  ← 围绕 icon 的环形进度条
│       ╰───╯             │
│     成就名称            │  ← 暗淡文字
│                         │
│    [稀有度徽章 暗淡]     │
└─────────────────────────┘
```

- 背景：`bg-neutral-100/50 grayscale`
- 环形进度条：SVG circle，围绕 icon 容器，stroke-dasharray 驱动进度
- 锁图标：绝对定位左上角，`opacity: 0.4`
- 文字：`text-neutral-400`，徽章 `opacity: 0.5`

### 2.3 保留的交互
- **3D 倾斜**：鼠标移动时 `rotateX`/`rotateY` 倾斜，`glowRef` 发光跟随鼠标
- **悬停**：卡片 `y: -10 scale: 1.02`
- **入场动画**：staggered `back.out(1.4)` 弹入

### 2.4 移除的内容
- ❌ `isFlipped` 状态及相关逻辑
- ❌ `handleClick` 翻转逻辑
- ❌ 背面 DOM（`rotateY(180deg)` 那块）
- ❌ 翻转提示图标

## 3. 详情弹窗设计

### 3.1 弹窗结构

```
┌──────────────────────────────────────┐
│  ╔════════════════════════════════╗  │
│  ║  ✨ [大 icon] ✨               ║  │  ← 48x48 或更大
│  ║                                ║  │
│  ║     成就名称                    ║  │
│  ║     [稀有度徽章]                ║  │
│  ║                                ║  │
│  ║  ─────────────────────────     ║  │
│  ║                                ║  │
│  ║  描述内容...                    ║  │
│  ║                                ║  │
│  ║  解锁时间: 2025-03-08 09:22   ║  │
│  ║                            [X] ║  │
│  ╚════════════════════════════════╝  │
│                                      │
│      [模糊遮罩背景]                   │
└──────────────────────────────────────┘
```

### 3.2 已解锁弹窗
- 边框为稀有度发光颜色 + `box-shadow`
- **解锁重播动画**：弹窗打开时，光效从中心 icon 向外扩散脉冲（GSAP timeline）
- **粒子漂浮效果**：CSS animation + 伪元素实现，稀有度越高粒子越密
- **传说级**：金色粒子雨背景

### 3.3 未解锁弹窗
- 整体暗色调，边框灰色
- icon 为灰度剪影，显示进度百分比
- 无粒子效果

### 3.4 弹窗动画序列（已解锁）
1. `0ms`：背景遮罩 `fadeIn`（200ms）
2. `100ms`：弹窗 `scale(0.8) opacity(0)` → `scale(1) opacity(1)`（300ms，`back.out` 缓动）
3. `200ms`：icon 外圈光效脉冲
4. `300ms`：边框发光出现
5. `400ms+`：粒子系统持续漂浮

### 3.5 关闭方式
- X 按钮点击
- 遮罩背景点击
- ESC 键

## 4. 稀有度特效层级

### 4.1 普通（common）
| 属性 | 值 |
|------|-----|
| 边框发光 | `opacity: 0.3`，无动画 |
| 背景 | 纯色 + 极淡渐变 |
| 悬停 | 边框微微变亮 |
| 弹窗粒子 | 无 |

### 4.2 稀有（rare）
| 属性 | 值 |
|------|-----|
| 边框发光 | 脉冲动画（每 2s 一次） |
| 背景 | 边框流光动画（赛博朋克风） |
| 悬停 | 流光加速 |
| 弹窗粒子 | 少量（5-10个），缓慢漂浮 |

### 4.3 史诗（epic）
| 属性 | 值 |
|------|-----|
| 边框发光 | 旋转光边（`background: linear-gradient` + `animation: translate`） |
| 背景 | 脉冲光晕扩散（每 3s 从中心扩散） |
| 悬停 | 光晕爆发 |
| 弹窗粒子 | 中等密度（15-20个） |

### 4.4 传说（legendary）
| 属性 | 值 |
|------|-----|
| 边框发光 | 金色火焰流光（从上往下滑动的金色光斑） |
| 背景 | 全屏金色粒子雨（从卡面上方飘落） |
| 悬停 | 金色粒子爆发 |
| 弹窗粒子 | 高密度金色粒子（30+）+ 边框金色流光 |

### 4.5 实现技术
- **粒子效果**：CSS `@keyframes` + `::before`/`::after` 伪元素，避免 canvas/three.js
- **流光边框**：CSS `background: linear-gradient` + `background-size: 200%` + `@keyframes translate`
- **脉冲光晕**：`box-shadow` 动画 + `scale` 脉冲
- **环形进度条**：SVG `<circle>` + `stroke-dasharray` / `stroke-dashoffset`

## 5. 组件结构变更

### 5.1 AchievementCard.tsx 变更
- 移除：`isFlipped` state、`handleClick` 翻转逻辑、`innerRef`（用于翻转的 wrapper）、背面 DOM
- 保留：`cardRef`、`glowRef`、`3D tilt` 逻辑、入场动画、解锁庆祝动画
- 新增：`环形进度条 SVG`、未解锁锁图标、`点击回调`（打开弹窗）
- 新增 props：`onCardClick?: (achievement: Achievement) => void`

### 5.2 新增 AchievementModal.tsx
- 详情弹窗组件
- 管理弹窗开关状态
- 处理遮罩点击和 ESC 关闭
- 根据 `achievement.unlocked` 决定渲染已解锁/未解锁版本
- 承载粒子效果和动画

### 5.3 数据流
```
AchievementCard (onClick) → AchievementModal (open with achievement data)
```

## 7. 设计决策记录

1. **为什么取消翻转？** 两面信息重复（icon + 名称），交互成本高但信息增量低。弹窗可以承载更丰富的内容且更有仪式感。
2. **为什么同尺寸不同特效？** 卡片网格需要统一尺寸保证布局整齐；稀有度差异通过特效层级体现，传说级华丽但普通级也不寒酸。
3. **为什么用 CSS 不用 canvas？** 项目已有 GSAP + CSS animation 体系，保持一致；CSS 伪元素足以实现粒子效果，性能可控。
4. **为什么环形进度条？** 相比底部横条，环形进度更游戏化（RPG 血条风格），且围绕 icon 不会额外占用空间。
